# 科研工作台使用与配置

使用 `get_workspace_context` 获取当前工作区、项目根目录、实际配置路径、运行模板目录，以及文档环境和模型调用入口。路径以返回结果为准；用户可能更改数据目录与运行环境目录。

## 工作方式

- 这是单用户、浏览器访问的本地工作台，无需平台账号。ChatGPT 授权属于模型连接，可与其他文字、语音服务并存。
- 材料直接保存在工作区文件系统中。论文、代码、译稿和实验产物按实际目录组织，不创建另一份材料登记。`workspace.json` 保存工作区身份、名称与时间。
- 对话名称、消息与工具历史保存在工作区 `.pi/sessions/<对话ID>.jsonl`。不要通过修改历史文件更改正在执行的会话。
- 当前打开的文件、预览模式、PDF 页码和用户选段会随问题提供。使用原生文件工具或 `read_pdf_pages` 读取需要的内容，使用 `open_document` 展示文件、指定预览模式或 PDF 页码。
- 需要编译 TeX、预览 Markdown、HTML 或了解嵌入页面的能力边界时，读取 `document-workbench`；翻译论文时读取 `paper-translation`。缺少环境时遵循对应技能的安装说明。

## 配置与排查

用户要求查看、修改配置或排查模型连接时，读取 [配置说明](references/configuration.md)。使用原生文件与命令工具操作实际文件，不生成第二份配置来源。

修改配置必须验证它能被对应的实际加载器加载。JSON 语法正确不等于配置可加载；配置可加载也不等于远端服务已连通。检查失败时修正本次修改，不能将失败结果报告为完成。说明实际完成了哪种检查，以及修改何时生效。

模型能力优先采用 Pi 已有信息及供应商实际返回值；缺失的信息由用户提供，或在明确的不确定性下使用原生默认值。不自行下载能力表、维护另一套模型目录或推测未确认的能力。
